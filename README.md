# Remix of PoshPlex ERP

We're going to create an e-commerce website called "Linea". It's going to be very minimalist and modern. 

To start I only want to create the header section. It's going to be the following two component:
1. Status bar -  A black status bar on the top showing alternating USPs (Free shipping over €50, 365 days warranty,  +100 000 happy customers  
2.  Menu - Three nav items on the left (Shop, Support, About), a logo in the middle (use text as a placeholder for now) and on the right a search icon, user icon and shopping bag icon.
